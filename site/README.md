# 共有導出ロジック

ここは一覧・詳細ページが共通で使うブラウザESモジュールです。canonical JSONは親ディレクトリに一度だけ置き、ここでは導出値を保存しません。

- `logic/character.js` — 状態差分の解決、武器の関連能力値、加入時技Lv補正、能力値ヒートマップ、術用の事実エビデンス
- `logic/spark.js` — 閃き可能数・総数・比率の都度計算
- `logic/data.js` — canonical JSONの読込とメモリ上の索引化
- `logic/recommendations.js` — 実データ分布から導く能力帯を最優先する武器順位。同じ能力帯では加入時技Lv補正、閃き可能率、閃き実数、関連能力値を比較

武器順位は「能力帯を優先し、同じ能力帯なら加入時技Lv補正、次に閃き範囲を優先する」という方針で実装済みです。能力帯の絶対しきい値は持たず、全キャラクターの実データ分布から毎回導出します。術の有効度計算は、通常術・冥術に関する検証済みの式がまだないため未実装です。キャラクター別の例外や固定重みは追加しません。

検証はプロジェクトルートで次を実行します。

```bash
python3 validate_data.py
node site/logic/character.test.mjs
```
